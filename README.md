# AI Chatbot

A lightweight Thai-language chatbot powered by the Typhoon API.

## Setup

1. Install the dependencies: `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and set `TYPHOON_API_KEY` in `.env`.
3. Start the API: `python app.py`
4. Open `index.html` in a browser. The page expects the API at `http://localhost:10000`.

Keep `.env` private. Do not commit API keys to the repository.
